# gamecentr-bot

Telegram-бот GameCentr: отправляете название игры — бот находит её в
[PS Store Украина](https://store.playstation.com/ru-ua/pages/latest), считает цену в UZS
по курсу и присылает название, цену и обложку.

**Какое издание берётся:**
- если у игры есть скидка — самое дешёвое издание по акции;
- если скидок нет — самое полное (самое дорогое) издание: Deluxe / Ultimate и т.п.

Скидки только для подписчиков PS Plus не учитываются. Курсы и прайс PS Plus — в `pricing.py`.

Что понимает бот:
- русские и народные названия: «гта 5», «ведьмак», «колда», «человек паук 2»;
- опечатки: «Elden Rng», «киберпак»;
- список игр столбиком — ответит по каждой и пришлёт итог;
- издания и сокращения: «Street fighter 6 ult», «Tekken 8 ultimate», «гта 5 премиум», «делюкс»;
- «найди самую дешёвую игру lego» — самая дешёвая игра из найденных;
- «Lego самые дешевые подборка (каких нет в подписке)» — 5 самых дешёвых игр без тех, что входят
  в PS Plus («топ 3» — три);
- фото обложки или скриншот — определит игру и пришлёт цену (нужен ключ Claude API).

Команды: `/start`, `/psplus` — прайс подписок PS Plus и EA Play.

## Диагностика поиска

Если бот пишет «не найдена» на игру, которая точно есть в магазине:

```bash
python debug_store.py "Tekken 8"
```

Скрипт покажет, что ответил PS Store и сколько игр удалось разобрать, и сохранит страницу
в `debug_search.html`.

## Claude API (необязательно)

Без ключа бот работает по правилам (словарь названий в `nlp.py`, транслит, нечёткое сравнение).
С ключом `ANTHROPIC_API_KEY` в `.env` сообщения разбирает Claude — он понимает любые формулировки,
исправляет опечатки и распознаёт игры на фото. Модель можно поменять переменной `CLAUDE_MODEL`
(по умолчанию `claude-sonnet-5-5`; мощнее — `claude-opus-5-5`, дешевле — `claude-haiku-5-5`).

## Проверка расчёта

Курс считается двумя независимыми способами, при расхождении бот не отправит цену. Тесты на все
границы диапазонов: `pip install pytest && python -m pytest tests`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # и впишите туда BOT_TOKEN
python bot.py
```

Бот должен работать на компьютере или сервере, которому доступны store.playstation.com
и api.telegram.org.
